# David Román López

Web development student (DAW) in Spain. Outside class I mostly build small tools for macOS and Linux in Go, Swift and shell, with as few dependencies as I can manage.

My final project, in progress, is a Go tool for working on a borrowed computer with my own tools instead of installing them there. It issues SSH certificates that expire after a few minutes and leaves both people a signed receipt of the session.

## Projects

- [jitterbreak](https://github.com/davidrlopez/jitterbreak): menu bar app in Go and Swift that stops the Wi-Fi ping spikes macOS causes when AWDL scans for nearby Apple devices.
- [smb-automount](https://github.com/davidrlopez/smb-automount): remounts SMB shares after sleep, wake or a VPN reconnect, with the passwords kept in the Keychain.
- [lambda-physics](https://github.com/davidrlopez/lambda-physics): physics learning site with a speedrun game that runs in the browser through WebAssembly, on a Fastify, TypeScript and PostgreSQL backend. Built in one week for a university deadline.
- [SQLmanager](https://github.com/davidrlopez/SQLmanager): desktop app in C# and Avalonia for an Oracle database, with credentials stored in the macOS Keychain or the Windows credential store.
- [SwiftHealthPatch](https://github.com/davidrlopez/SwiftHealthPatch): SwiftUI demo app for a simulated wearable medical patch that sends vital signs over Bluetooth.
- [OracleDBmacOS](https://github.com/davidrlopez/OracleDBmacOS): how to run Oracle Database on Apple Silicon with Colima and Docker.

Coursework lives in [JavaClase](https://github.com/davidrlopez/JavaClase), [phpClass](https://github.com/davidrlopez/phpClass), [jsClass](https://github.com/davidrlopez/jsClass) and [HTML-CSS-Projects](https://github.com/davidrlopez/HTML-CSS-Projects).
